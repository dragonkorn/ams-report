## 1 รอบ = CSV 8 ไฟล์

โหลดจากระบบกลางของ AIA ทีละไฟล์ เบราว์เซอร์ตั้งชื่อซ้ำแล้วต่อท้าย `(1)` `(2)` `(3)` เอง

| ชนิด | ระดับ | จำนวน |
|---|---|---|
| Case | Agency + Agent | 2 |
| FYP | Agency + Agent | 2 |
| FYC **All Product** | Agency + Agent | 2 |
| FYC **เฉพาะ Life** | Agency + Agent | 2 |

## encoding

**TIS-620** → `new TextDecoder('windows-874')`

## แยกชนิดจากเนื้อไฟล์ ห้ามดูชื่อไฟล์

```
บรรทัด 1 ช่องแรก = ชนิด   Case | FYP | FYC
บรรทัด 2 ช่องแรก = ระดับ   Agency | Agent
บรรทัด 3 เป็นต้นไป = ข้อมูล
```

ชื่อไฟล์เชื่อไม่ได้ ลำดับ `(1)(2)(3)` **ไม่คงที่ข้ามหน่วย**:

| หน่วย | `AMSDailyKRAFyp.csv` คือ |
|---|---|
| VP7 | Agency |
| VP27 | **Agent** |
| VP82 | Agent |

## คอลัมน์

คอลัมน์แรกเสมอ = `รหัส 10 หลัก : คำนำหน้า ชื่อ นามสกุล`

### Case / FYP — 14 คอลัมน์

```
0 ชื่อ            1 GA
2 MTD LastYear    3 MTD CurrentYear   4 MTD Growth%   5 CMTD Sub
6 YTD LastYear    7 YTD CurrentYear   8 YTD Growth%   9 CYTD Sub
10 CMTD PaidVsSub 11 CYTD PaidVsSub
12 MonthEndOfLastYear   13 YearEndOfLastYear
```

### FYC — 11 คอลัมน์ (คนละ schema)

```
0 ชื่อ            1 GA            2 Current
3 MTD LastYear    4 MTD CurrentYear   5 MTD Growth%
6 YTD LastYear    7 YTD CurrentYear   8 YTD Growth%
9 MonthEndOfLastYear   10 YearEndOfLastYear
```

**FYC ไม่มีคอลัมน์ Sub (นำส่ง) เลย** มีแต่อนุมัติ และมีคอลัมน์ `Current` ที่ Case/FYP ไม่มี

โค้ด: `CASE_FYP_COLUMNS` / `FYC_COLUMNS` ใน [types.ts](../app/src/lib/types.ts)

## ระบุหน่วย

ไฟล์ระดับ **Agency** มีรหัสหน่วยในคอลัมน์แรก:

| รหัส | หน่วย | GA |
|---|---|---|
| `01001 : ตัวอย่าง 3 วีพี 7` | VP7 | `01B` |
| `01002 : ตัวอย่าง 3 วีพี 27` | VP27 | `35Q` |
| `01003 : ตัวอย่าง 3 วีพี 82` | VP82 | `01B` |
| `01004 : ตัวอย่าง 3 วีพี 87` | VP87 | `35Q` |
| `01005 : ตัวอย่าง 3 วีพี 90` | VP90 | `01B` |

**คอลัมน์ GA ใช้ระบุหน่วยไม่ได้** — 3 หน่วยใช้ `01B` เหมือนกัน
ไฟล์ระดับ Agent ไม่มีรหัสหน่วยเลย ต้องเอาจากไฟล์ Agency ในชุดเดียวกัน

## แยก FYC All Product ออกจาก Life

**หัวไฟล์เหมือนกัน 100%** แยกจาก header ไม่ได้ → เทียบยอดรวม YTD Current Year
**All Product ≥ Life เสมอ** (All = L+SP+Gr+PA)

ตรวจแล้วแยกถูกทั้ง 5 หน่วย แต่ UI ยังมีปุ่มสลับเผื่อพลาด — `swapFycScopes()`

## กับดักในข้อมูลดิบ

### roster ไม่เท่ากันระหว่าง feed

VP82 รหัส `620992` **มีเฉพาะไฟล์ FYC All Product** ไม่มีใน Case / FYP / FYC Life
report ต้นฉบับลง 0 ทุกช่องที่ขาด → ต้อง **outer join เติม 0** ไม่ใช่ inner join

### CSV มีทุกคนในหน่วย รวมคนที่ตัดสัญญาไปแล้ว

| หน่วย | คนใน CSV | คนใน report | ตัดออก |
|---|---|---|---|
| VP7 | 25 | 21 | 4 |
| VP27 | 9 | 7 | 2 |
| VP82 | 18 | 13 | 5–6 |
| VP87 | 5 | 3 | 2 |
| VP90 | 8 | 6 | 2 |

CSV **ไม่มีคอลัมน์สถานะสัญญา** เลย กรองอัตโนมัติไม่ได้ → ผู้ใช้ต้องตั้ง `rosterStatus` เอง

### ชื่อไทยมี `?` ปนของจริง

```
0000590011 : นา???สาว กล่องกมล เฉลิมฤทธิชัย
0000240153 : นางสาว ม???นี ปิติกุล
```

ตรวจ raw byte แล้วเป็น `0x3F` จริง ๆ — **ระบบต้นทางของ AIA ทำข้อมูลเสียเอง ไม่ใช่ decode ผิด**
→ ช่องแก้ชื่อย่อด้วยมือเป็นของบังคับ

### ไม่มีวันที่ในไฟล์

ทั้งหัวไฟล์และท้ายไฟล์ ไม่มีวันที่เลย ผู้ใช้ต้องเลือก `asOfDate` เอง
เป็นต้นเหตุของกับดักใหญ่ที่สุดในโปรเจค → [05-pitfalls.md](05-pitfalls.md)

## xlsx รอบเก่า — ใช้ seed ประวัติ

ไฟล์ report ที่เคยทำมือไว้แล้ว ใช้นำเข้าครั้งเดียวต่อหน่วย เพื่อไม่ต้องรอสะสมกริด Active เป็นปี

**ไฟล์พกวันที่ของตัวเองมาด้วย** (ช่อง `B4` เช่น `วันที่ 30 ก.ค.2569`) อ่านไม่ได้ = ไม่ยอมนำเข้า
วันที่นี้ **เป็นอิสระจากรอบ CSV** ที่กำลังบันทึก — ไฟล์อาจเป็นของเดือนก่อนหรือปีก่อนก็ได้

ดึงออกมา:

| ช่อง | ได้อะไร | เก็บใต้ |
|---|---|---|
| C, D, E, G, H | ชื่อย่อ · วันที่ออกรหัส · MOC · สถานะ · หมายเหตุ | ผูกกับคน ไม่ผูกกับรอบ |
| S..AD | กริด Active 12 เดือน | ปีของไฟล์ |
| AE..AH | Limra 4 ค่าต่อคน | วันที่ของไฟล์ |
| แถวสรุป O..R | Limra ระดับหน่วย | วันที่ของไฟล์ |
| B3, B4, AE3, คอลัมน์ S ล่าง | หัวหน่วย · วันที่ · วันที่ Limra · ข้อความปลุกใจ | ผูกกับหน่วย |
