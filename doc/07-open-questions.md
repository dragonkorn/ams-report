# คำถามค้าง

[← กลับสารบัญ](MOC.md)

เรื่องที่ยังไม่รู้จริง ตอบได้แค่เจ้าของงาน ไม่มีอะไรบล็อกการใช้งาน แต่กระทบความเป๊ะ

## 1. สีพีชในตาราง Limra แปลว่าอะไร

เจอ 2 ช่องเป็นพีช `#FFCC66` ที่ค่า **77.15** และ **89.93** ซึ่งไม่เข้ากฎแถบสีใดเลย
ค่าใกล้เคียงกันในช่องอื่นเป็นแดง/ส้ม

**ตอบแล้ว (12 ส.ค. 2569):** ทำมือพลาด ไม่ทำสีพีช ใช้ 4 แถบมาตรฐาน

## 2. เส้นแบ่งแดง/ส้มอยู่ที่เท่าไหร่

**ตอบแล้ว (12 ส.ค. 2569): 80** — `LIMRA_ORANGE_FLOOR = 80`
ในไฟล์ 30 ก.ค. เส้นตกที่ 84 (84.03 แดง · 84.04 ส้ม) แต่นั่นทาด้วยมือ ไม่ใช่กฎ

## 3. สถานะขั้นที่ 3 เรียกว่าอะไร แยกย่อยไหม

คนที่ไม่ขึ้น report — เรียกรวมว่า `ตัดสัญญา` พอ หรือต้องแยก ลาออก / ย้ายหน่วย / สัญญาจบ?

**ตอนนี้:** ใช้ `ended` → แสดงเป็น `ตัดสัญญา`

**เกี่ยวข้อง:** ตอนนี้ยังแยก "ตัดสัญญาจริง" ออกจาก "รหัสใหม่ที่ยังไม่ได้ตั้งค่า" ไม่ได้ เพราะทั้งคู่เป็น `ended` เหมือนกัน
ถ้าจะแยกต้องเพิ่ม field เช่น `statusConfirmed` แล้วทำแถบเตือน "เจอรหัสที่ไม่เคยเห็น" ในหน้าตัวแทน
→ [05-pitfalls.md ข้อ 6](05-pitfalls.md)

## 4. ฟอนต์ — ยอมให้ต่างได้แค่ไหน

ต้นฉบับใช้ **CordiaUPC** ซึ่งมากับ MS Office แจกจ่ายต่อไม่ได้

**ตอนนี้:** เรียกด้วยชื่อ ให้เครื่องที่ export หาเอง สำรองเป็น Sarabun
เนื่องจากส่งออกเป็น PDF/PNG ที่เรนเดอร์บนเครื่องผู้ใช้เอง ถ้าเครื่องมี Office อยู่แล้วจะตรงต้นฉบับเป๊ะโดยไม่ติดลิขสิทธิ์
**ยังไม่ได้ยืนยันด้วยตาว่าออกมาเหมือนจริง**

## 5. สีข้อความปลุกใจ ต้องแยกต่อบรรทัดไหม

ต้นฉบับ VP7 เลือกสีมือทีละบรรทัด: เหลือง / แดง / ไม่มีสี / เขียว — ไม่มีกฎ

**ตอนนี้:** ใช้เหลืองทั้งหมด
ถ้าต้องการสีต่อบรรทัด ต้องเก็บสีเป็น field เพิ่มใน `units.rallyLines`

## 6. จะให้ยึดสไตล์ของหน่วยไหน

แต่ละหน่วยทำมือ สไตล์ต่างกันจริง (สีหัว ความกว้างคอลัมน์ คำในหัวตาราง)
→ ตาราง diff ใน [02-report-spec.md](02-report-spec.md#ความต่างระหว่างหน่วย--ไม่มีคำตอบเดียว)

**ตอนนี้:** ยึด VP7 ทุกหน่วย
ถ้าต้องการให้ตรงรายหน่วย ต้องทำเป็นค่าตั้งต่อหน่วยใน store `units`

## 7. ยังไม่มี CSV ย้อนหลังจริงมาทดสอบ backfill

`exampleFiles_2/` มี snapshot เดียว (30 ก.ค.2569) ทุกหน่วย
สูตร `YTD − MTD` พิสูจน์ได้แค่ทางอ้อม (ช่องเดือนปัจจุบันตรงกับ MTD ทุกแถว) แต่ยังไม่เคยรัน 2 เดือนจริงต่อกัน

ถ้ามี CSV ของเดือนก่อน ๆ เก็บไว้ ส่งมาจะทดสอบได้เต็ม
ระหว่างนี้ประวัติมาจากการนำเข้า xlsx เดิม ซึ่งได้ผลเหมือนกันแต่ไม่ได้ทดสอบตัวสูตร

## เรื่องที่ตอบไปแล้ว

| คำถาม | คำตอบ |
|---|---|
| ทำไม CSV มีคนเกิน report | CSV มีทุกคนในหน่วย คนที่สัญญาจบไปแล้วไม่ขึ้น report |
| พักสัญญาขึ้น report ไหม | ขึ้น พร้อมไฮไลต์เหลืองและหมายเหตุ "ต้องแก้ Q นี้" |
| ปีตัด MOC | เดาจากปีไม่ได้ → เป็นช่องกรอกที่ระบบเสนอค่าให้ |
| มีไฟล์ Limra ไหม | ไม่มี พิมพ์มือทั้งหมด |
| เก็บข้อมูลที่ไหน | IndexedDB อย่างเดียว ไม่ขึ้น cloud |
