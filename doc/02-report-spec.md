ใช้ร่วมกันทั้ง [xlsxImport.ts](../app/src/lib/xlsxImport.ts) · [xlsxExport.ts](../app/src/lib/xlsxExport.ts) · [Report.tsx](../app/src/ui/Report.tsx)

## โครงหน้า

```
แถว 2–5    หัวตาราง
แถว 6..n   ตัวแทน 1 คนต่อแถว เรียงตามรหัสจากน้อยไปมาก
แถว n+1    ว่าง สูง 5.25
แถว n+2    รวม (SUM)
แถว n+3    ว่าง สูง 15.75
4 แถวถัดมา หัวบล็อกสรุปหน่วย
4 แถวถัดมา Case / FYP / FYC (L+SP+Gr+PA) / FYC เฉพาะ Life
แถวสุดท้าย คำเตือนความลับ
```

**บล็อกล่างไม่ได้ตรึงแถว** ไหลตามจำนวนคน — VP7 (21 คน) สรุปแถว 30 · VP27 (7 คน) แถว 16 · VP90 (6 คน) แถว 15

## รูปแบบตัวเลข ← ข้อที่พลาดกันบ่อยที่สุด

| ประเภท | format | ตัวอย่าง |
|---|---|---|
| **ทุกช่องเงินและจำนวน** | `#,##0` | `12,345` **ไม่ใช่** `12,345.40` |
| Limra % (AE, AG) | `#,##0.00` | `93.91` |
| Growth % ในบล็อกสรุป | `General` | `150` · `-36.54` · `1.7` (ไม่ใช่ `1.70`) |
| ช่อง `9/12` (AL) | `@` ข้อความ | `5/12` |

**ต้นฉบับไม่มีทศนิยมในคอลัมน์เงินเลย** ค่าที่เก็บคือ `12345.4` แต่แสดง `12,345`
ยืนยันด้วย ExcelJS และ openpyxl ตรงกัน

## การจัดตำแหน่ง

```
center   B  D  E  G  H  S..AD  AE  AG  AI  AK  AL
```

**ชื่อเดือน S4:AD5 หมุน 90° อ่านจากล่างขึ้นบน** (`textRotation: 90`) เพื่อบีบความกว้าง 12 คอลัมน์
ในต้นฉบับวางแนวนอน · หน้าจอใช้ `writing-mode: vertical-rl` + `rotate(180deg)` ที่ `<span>` ข้างใน
(หมุนที่ `<td>` ตรง ๆ เส้นขอบจะหมุนตาม)

### กฎระบายสีรายเซลล์ในแถวตัวแทน

**N (Case อนุมัติเดือนนี้) เป็นตัวคุมเกือบทั้งแถว** ผลผลิตที่ไม่มี Case อนุมัติหนุนอยู่ ไม่ติดสี

| ช่อง | ระบายเมื่อ | สี |
|---|---|---|
| B–H | สถานะ = พักสัญญา | เหลือง |
| B–H | N > 0 | เขียวอ่อน |
| H **ตัวอักษร** | หมายเหตุ = `ต้องแก้ Q นี้` | แดง (พื้นยังตามแถว) |
| I–L | ทุกแถว | เขียวอ่อน |
| M | M > 0 | ชมพู |
| N | N > 0 | เขียวอ่อน |
| O | O > 0 **และ** N > 0 | ชมพู |
| P | P > 0 **และ** N > 0 | เขียวอ่อน |
| Q · R | ค่า > 0 **และ** N > 0 | ฟ้าอ่อน |
| S–AD | ค่า > 0 | สีของไตรมาสนั้น |
| S–AD | ว่าง และเป็นเดือน**ก่อน**เดือนของรอบ | เทา |
| AE–AH | แถบ Limra | ดู [03](03-calculation-rules.md#แถบสี-limra) |
| AI | = 240,000 (ขึ้นขั้นบน) | เขียวอ่อน |
| AJ | = `ครบแล้ว` | เขียวอ่อน |
| AK | ≥ 9 ราย | เขียวอ่อน |
| AL | `activeCount + เดือนที่เหลือ < 9` | เทา |

`เดือนที่เหลือ = 11 − index เดือนของรอบ` — รอบตัดสิ้นเดือน เดือนของรอบจึงถือว่าใช้ไปแล้ว
แต่กริด S–AD ยังไม่เทาเดือนของรอบ เพราะยอดเดือนนั้นยังไม่นิ่ง (`provisionalMonth`)

**ช่องที่ไม่ระบายยังต้องตีเส้นขอบ** ถ้าไม่ตี Excel จะโชว์ gridline ตัวเองแทน ตารางจะขาดเป็นแถบ

**บล็อกข้อความปลุกใจไม่มีเส้นคั่นระหว่างบรรทัด** มีแต่กรอบรอบนอก — เป็นข้อความก้อนเดียว
ที่เขียนหลายบรรทัด ไม่ใช่ตารางที่แต่ละช่องเป็นคนละเรื่อง (กรอบไฮไลต์ "ช่องที่พิมพ์มือ" ตอนตรวจ
ก็ตีรอบทั้งบล็อกด้วยเหตุผลเดียวกัน)

**เส้นขอบบนจอเป็น `1px solid #595959`** เคยใช้ `0.5px` แล้วเส้นหายไปเลยในกริด Active
เพราะเส้นครึ่งพิกเซลถูกปัดทิ้งที่ zoom บางระดับและตอน export รูป ซึ่งเห็นชัดที่สุดตรงช่องแคบ ๆ
ที่มีพื้นสี — เส้นเทาอ่อนบนพื้นเขียวมะนาวแทบไม่ต่างกัน

**ช่องเบี้ยหายไปใช้สีแถบเดียวกับ % ข้าง ๆ** `AF` ตามสี `AE` · `AH` ตามสี `AG` ไม่มีข้อยกเว้น

### สีบล็อกสรุปหน่วย

ระบายตาม**คอลัมน์** ไม่มีเงื่อนไขค่า ยกเว้น 2 ข้อล่างสุด — หัวตารางกับแถวข้อมูลใช้สีเดียวกัน

| คอลัมน์ | สี |
|---|---|
| B:E หัว | เขียวอ่อน · แถวข้อมูลไม่ระบาย |
| F Month End of Last Year · H CMTD Sub · J Growth % เดือน | ชมพู |
| G MTD Last Year · L YTD Last Year | ไม่ระบาย |
| I MTD Current Month · M YTD Current Year | เขียวอ่อน · **แถว FYC เป็นฟ้าอ่อน** |
| K Year End · N Growth % ปี | เหลือง |
| O–R Limra หน่วย | พีช (ไม่ใช้แถบสี Limra) |

- **H ของแถว FYC ไม่ระบาย** เพราะ feed FYC ไม่มียอดนำส่ง (`cmtdSub = null`)
- **Growth ติดลบ → ตัวอักษรแดง** ทั้ง J และ N (ต้นฉบับเจอที่ N ของแถว Case `-36.54`)

### ที่ไฟล์ต้นฉบับ 30 ก.ค.69 ไม่ตรงกับกฎข้างบน

ไฟล์ชุด 30 ก.ค. เป็นรุ่นเก่ากว่า เจ้าของงานยืนยันกฎใหม่จากไฟล์ 21/31 ก.ค.69:

- แถวข้อมูล M–R ในไฟล์เก่า **ไม่ระบายเลย** (ระบายแค่แถวรวม) · ไฟล์ใหม่ระบายตามตาราง
- ไฟล์เก่า **ไม่มีสีเทา** ทั้งกริดและ AL
- AI/AJ/AK ไฟล์เก่าระบายรายเซลล์อยู่แล้ว ยืนยันกฎนี้ตรงกัน
- รหัส 410513 มี P = 3,500 แต่ N = 0 → **B–H ไม่เขียว** ยืนยันว่า N เท่านั้นที่คุมสีแถว

## สูตรที่ต้องคงไว้ ไม่ใช่ค่าตาย

| ช่อง | สูตร | เหตุผล |
|---|---|---|
| แถวรวม | `SUM(X6:X{n+1})` | ช่วงกินแถวว่างคั่นด้วย ตามต้นฉบับ |
| AJ (ยังขาดอยู่) | `=AI{r}-K{r}` | แก้ FYC ใน Excel แล้วยอดขาดขยับตาม |
| บล็อกล่าง B{t+2} | `=B4` | แก้วันที่ที่เดียว ขยับทั้งใบ |
| บล็อกล่าง O{t} | `=AE3` | เช่นเดียวกับวันที่ Limra |

ถ้า FYC ถึงเป้าแล้ว ช่อง AJ เป็นข้อความ `ครบแล้ว` ไม่ใช่สูตร
