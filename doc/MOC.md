# MOC — สารบัญความรู้โปรเจค AMS Report Tool

> หมายเหตุคำซ้ำ: **MOC** ในไฟล์นี้ = *Map of Content* (สารบัญ)
> ส่วน **MOC** ที่พูดถึงในเนื้อหา report = *เงื่อนไขการรักษาสัญญาตัวแทน* คนละเรื่องกัน

## นี่คืออะไร

เครื่องมือแทนการก๊อบตัวเลขจาก CSV ของ AIA วางลง xlsx ทีละช่อง
ลาก CSV เข้าเว็บ → ได้ report หน้าตาเหมือนเดิม → ส่งออก PDF / xlsx / PNG
ทำงานในเบราว์เซอร์ล้วน ไม่มี server ข้อมูลไม่ออกจากเครื่อง

**ผู้ใช้จริง 1 คน ดูแล 5 หน่วย** — VP7 · VP27 · VP82 · VP87 · VP90 · ทำเดือนละครั้ง

## หาโค้ดตรงไหน

```
app/
  src/lib/csv.ts          อ่าน CSV, แยกชนิด/ระดับ/หน่วย, แยก FYC All vs Life
  src/lib/snapshot.ts     รวม 4 feed เป็นแถวเดียวต่อคน + ลายนิ้วมือรอบ
  src/lib/compute.ts      กติกาทั้งหมด — FYC ladder, กริด Active, แถบสี Limra, MOC
  src/lib/format.ts       รูปแบบตัวเลข/วันที่/ชื่อย่อ
  src/lib/xlsxImport.ts   นำเข้าประวัติจาก xlsx เดิม
  src/lib/xlsxExport.ts   เขียน xlsx กลับออกไป
  src/lib/imageExport.ts  บันทึก PNG ความละเอียดสูง
  src/db/index.ts         Dexie + storage.persist() + กั้นเบราว์เซอร์
  src/ui/Report.tsx       replica ที่แสดงบนจอและใช้พิมพ์ PDF
  test/                   golden test เทียบกับ xlsx ต้นฉบับ 5 หน่วย
```

## รันยังไง

```bash
cd app
npm install
npm run fixtures   # แตกไฟล์ตัวอย่างจาก exampleFiles_2/ ไปที่ app/fixtures/
npm test           # เทียบกับ xlsx ต้นฉบับทั้ง 5 หน่วย
npm run dev
```

**ต้องเปิดด้วย Chrome หรือ Edge** — Safari ล้าง IndexedDB ถ้าไม่เข้าเว็บ 7 วัน ซึ่งงานนี้ทำเดือนละครั้ง

## เรียกช่องใน report ยังไง

ใช้ **ตัวอักษรคอลัมน์แบบ Excel** เป็นชื่อกลาง — ตรงกันทั้ง xlsx ต้นฉบับ ไฟล์ที่ export โค้ด และเอกสาร
ตารางเต็ม: **[08-column-reference.md](08-column-reference.md)**

| จะพูดถึง | พูดว่า |
|---|---|
| ทั้งคอลัมน์ | `คอลัมน์ AJ` |
| ช่องของคนหนึ่ง | `รหัส 240153 ช่อง K` — เลขแถวเลื่อนตามจำนวนคนแต่ละหน่วย จึงอ้างด้วยรหัสแทน |
| ช่องในกริด Active | `กริด ก.ค. ของ 240153` หรือ `คอลัมน์ Y` |
| บล็อกสรุปหน่วย | `แถวสรุป FYP ช่อง N` — ต้องบอกแถวด้วย |
| เปิด xlsx อยู่ | `K17` ตรง ๆ ได้เลย |

⚠️ **ตัวอักษรเดียวกันคนละความหมายระหว่างบล็อก** — `I` ในบล็อกตัวแทน = Case สะสมปี
แต่ `I` ในบล็อกสรุป = MTD Current Month จึงต้องระบุบล็อกเสมอ

⚠️ ชื่อไทยกำกวม 2 จุด: `FYC เดือนนี้` ไม่รู้ว่า Q หรือ R · `FYC` เฉย ๆ ไม่รู้ว่า All Product หรือ เฉพาะ Life

## หลักการที่ยึดตลอด

1. **ไฟล์ต้นฉบับคือความจริง** ทุกกฎในเอกสารนี้ถอดจาก xlsx จริง 5 หน่วย 50 ตัวแทน ไม่ใช่การเดา
2. **กติกาแยกจาก React** ทุกอย่างใน `src/lib/` เป็น pure function ทดสอบได้โดยไม่ต้องมี DOM
3. **ตัวเลขต้องพิสูจน์ได้** เปลี่ยนอะไรที่กระทบผลลัพธ์ ต้องมี test เทียบกับต้นฉบับ
4. **ข้อมูลไม่ออกจากเครื่อง** ชื่อ/รหัส/เบี้ย/คอมมิชชั่นเป็นข้อมูลส่วนบุคคล
   repo นี้เป็น **public** → ห้าม commit ข้อมูลจริงลงไฟล์ไหนทั้งสิ้น ตัวอย่างทุกที่เป็นของสมมติ
   กติกาเต็ม: [06-testing.md](06-testing.md#ห้ามมีข้อมูลจริงใน-repo--repo-นี้เป็น-public)
