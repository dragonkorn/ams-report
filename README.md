# AMS Report Tool

เครื่องมือทำ **report ผลผลิตตัวแทน** รายเดือนจากไฟล์ CSV ที่ AIA ส่งมา
แทนการก๊อบตัวเลขวางลง xlsx ทีละช่อง — ลาก CSV เข้าเว็บ แล้วได้ report หน้าตาเดิม
ส่งออกเป็น **xlsx · PNG · PDF** ได้

**ทำงานในเบราว์เซอร์ล้วน ไม่มี server** ไฟล์ที่ลากเข้าไปไม่เคยถูกอัปโหลดไปไหน
ข้อมูลเก็บใน IndexedDB ของเครื่องตัวเอง

## ใช้งาน

เปิด <https://dragonkorn.github.io/ams-report/> ด้วย **Chrome หรือ Edge**
(Safari ล้าง IndexedDB ถ้าไม่เข้าเว็บ 7 วัน ซึ่งงานนี้ทำเดือนละครั้ง)

## รันเอง

```bash
cd app
npm install
npm run dev
npm test        # ข้ามอัตโนมัติถ้าไม่มีไฟล์ตัวอย่างในเครื่อง
```

## เอกสาร

เริ่มที่ [doc/MOC.md](doc/MOC.md) — สเปกไฟล์เข้า ผัง report กติกาคำนวณ สถาปัตยกรรม กับดัก และการทดสอบ

## ข้อมูลจริงไม่อยู่ใน repo นี้

รหัสตัวแทน ชื่อ เบี้ย และคอมมิชชั่นเป็นข้อมูลส่วนบุคคล
ไฟล์ตัวอย่าง (`*.csv` `*.xlsx` `*.pdf` `*.zip`) ถูก ignore ทั้งหมด และตัวอย่างในเอกสาร/test เป็นของสมมติ
กติกา: [doc/06-testing.md](doc/06-testing.md#ห้ามมีข้อมูลจริงใน-repo--repo-นี้เป็น-public)
